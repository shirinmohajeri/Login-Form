## Bootstrap Classes Used

| Class | Description |
|---|---|
| `container` | Wraps and centers content |
| `d-flex` | Enables flexbox |
| `justify-content-center` | Centers horizontally |
| `align-items-center` | Centers vertically |
| `min-vh-100` | Full screen height |
| `text-center` | Centers text |
| `p-5` | Adds padding |
| `mb-4` | Margin bottom |
| `mx-auto` | Centers element |
| `form-control` | Bootstrap input style |
| `border-0` | Removes border |
| `bg-transparent` | Transparent background |
| `shadow-none` | Removes Bootstrap shadow |
| `btn` | Bootstrap button |
| `w-100` | Full width |

## Important CSS Concepts

### Outer Shadow

```css
box-shadow:
  15px 15px 30px #c7cad1,
  -15px -15px 30px #ffffff;
```

Creates the neumorphism raised effect.

---

### Inner Shadow

```css
box-shadow:
  inset 6px 6px 12px #c7cad1,
  inset -6px -6px 12px #ffffff;
```

Creates the pressed input effect.
