A modern, responsive login interface built with **HTML5**, **CSS3**, and **Bootstrap 5**. The project showcases a clean authentication screen featuring a glassmorphism-inspired design, gradient background, smooth hover animations, and a mobile-friendly layout.

# 🚀 Getting Started

No installation or build tools are required.

## Clone the repository

```bash
git clone https://github.com/shirinmohajeri/login-ui.git
```

## Open the project

Simply open **index.html** in your browser.

Or run a local server.

Using VS Code Live Server:

1. Install the Live Server extension.
2. Right-click **index.html**
3. Select **Open with Live Server**

Alternatively:

```bash
python -m http.server
```

or

```bash
npx serve .
```
